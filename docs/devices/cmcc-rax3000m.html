刷机教程

1

准备工作

  • 下载 chawrt 固件：cmcc-rax3000m-squashfs-factory.bin
  • 准备网线连接电脑和路由器 LAN 口
  • 备份原厂固件（可选但推荐）
2

进入 Breed/Uboot

  • 断电状态下按住 Reset 键
  • 上电保持 5-10 秒后松开 Reset
  • 电脑网卡 IP 设为 192.168.1.2，子网掩码 255.255.255.0
  • 浏览器访问 192.168.1.1 进入 Breed/Uboot 界面
3

刷入固件

  • 在 Breed/Uboot 界面选择"固件更新"或"Firmware Update"
  • 选择下载的 factory.bin 固件文件
  • 点击上传/更新，等待进度条完成
  • 刷写完成后自动重启（如未自动重启，手动重启设备）
4

首次启动

  • 等待 2-3 分钟系统初始化
  • 电脑网卡设置为自动获取 IP（DHCP）
  • 访问 192.168.1.1 进入 LuCI 管理界面
  • 默认无密码，首次登录会要求设置管理员密码

恢复原厂固件

方法 1：通过 Breed 恢复

如之前备份了原厂固件，可在 Breed 界面刷入备份文件恢复。

方法 2：使用官方工具

联系电信运营商获取官方固件恢复工具，或使用官方提供的救砖方案。

常见问题

刷机后无法启动，LED 灯不正常

可能原因：

  • 固件型号不匹配 - 确认下载的是 RAX3000M 专用固件
  • 刷写过程中断 - 重新进入 Breed 尝试再次刷入

解决方法：

  1. 尝试进入 Breed（按 Reset 上电）
  2. 如能进入 Breed，重新刷入正确固件
  3. 如无法进入 Breed，可能需要 TTL 救砖
WiFi 无法使用或搜索不到信号

解决方法：

  1. 登录 LuCI 界面：192.168.1.1
  2. 进入"网络" → "无线"
  3. 点击"添加"或"启用"无线网络
  4. 设置 SSID（WiFi 名称）和密码
  5. 点击"保存&应用"

首次刷入 chawrt 后，WiFi 默认是禁用状态，需要手动配置启用。

无法进入 Breed/Uboot 界面

检查事项：

  • 确认按 Reset 的时机：必须是断电状态下按住，然后上电
  • 按住时间是否足够：建议保持 8-10 秒
  • 电脑 IP 配置：必须手动设置为 192.168.1.x 网段
  • 网线连接：必须连接到 LAN 口，而非 WAN 口

替代方法：

部分批次的 RAX3000M 可能未预装 Breed，可通过官方固件的漏洞或 TTL 串口刷入 Breed。

刷机后网速变慢

优化建议：

  1. 检查 WiFi 信道设置，避开拥挤信道
  2. 确认硬件加速已启用（LuCI → 网络 → Turbo ACC）
  3. 关闭不必要的服务和插件
  4. 更新到最新版本固件
