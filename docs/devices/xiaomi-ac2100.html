刷机教程

小米 AC2100 通过官方 Web 管理页或 CLI 升级 OpenWrt ChaWrt。请根据以下步骤逐步操作：

1

准备工作

  • 下载对应的 openwrt-ramips-mt7621-*-xiaomi_ac2100-factory.bin 或 *-initramfs-recovery.itb。
  • 将电脑接入 LAN 口，确保路由器和 PC 在同一子网。
  • 备份原厂配置（Web 页面或 cfg_export_config_file.conf），防止误操作。
2

使用 MiWiFi Web 升级

  • 登录 http://192.168.31.1（默认管理员）进入系统设置 → 系统升级。
  • 上传 factory 镜像，勾选“保留设置”视需要，并点击升级。升级完成后设备将自动重启。
  • 首次进入 ChaWrt Web，请设置 root 密码，开启 SSH 以便后续维护。
3

首次配置与固化

  • SSH 登录：ssh root@192.168.31.1，按提示设置密码与网络。
  • 使用 sysupgrade -v openwrt-ramips-mt7621-*-xiaomi_ac2100-squashfs-sysupgrade.itb 完成固化。
  • 建议禁用 Xiaomi Cloud 模式，使用 ChaWrt 自带的认证组件与 LuCI。
4

后续升级

  • 再次升级请直接使用 sysupgrade 镜像，在 LuCI 或 CLI 中执行 sysupgrade。
  • 如需保留配置，可加参数 sysupgrade -c，升级前请确保配置兼容。

恢复原厂 / 进入救援

如果 Web 界面无法访问，可按住 RESET 键不放，接通电源 5 秒后等待 LED 闪烁，此时设备进入 TFTP 恢复模式。将电脑设为 192.168.1.10，启动 TFTP 服务并传送 recovery 镜像（*-initramfs-recovery.itb），即可临时进入 ChaWrt。

恢复原厂建议先备份 cfg_export_config_file.conf，并参考官网工具重新写入官方固件。

常见问题

刷机后能否继续使用小米官方 App？

ChaWrt 替代官方固件后会失去小米 App 管理能力，建议使用 ChaWrt 自带 Web UI 或 LuCI 进行配置，并通过 QQ 群获取支持。

如何在 ChaWrt 中恢复配置？

可通过 LuCI → 系统 → 备份/升级 恢复 backup.tar.gz 文件，或手动编辑 /etc/config/ 下的配置文件。
