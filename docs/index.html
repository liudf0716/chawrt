项目介绍

关于 chawrt

chawrt 是基于 OpenWrt 的深度优化版本，专注于专业商用 WiFi 场景，面向企业、运营商及公共场所网络部署。

项目在保持 OpenWrt 核心特性的基础上，集成了认证门户、内网穿透、VPN、流控、DPI 等企业级功能，并通过公安三所认证要求，满足国内网络安全合规需求。

核心优势

  • ✓ 公安三所认证合规
  • ✓ 企业级认证门户
  • ✓ 完整的 VPN 解决方案
  • ✓ 高性能流量控制
  • ✓ 深度包检测（DPI）

编译指南

1

安装依赖

在 Ubuntu/Debian 系统上安装编译所需的依赖包：

sudo apt update
sudo apt install -y build-essential clang flex bison g++ gawk \
gcc-multilib g++-multilib gettext git libncurses5-dev libssl-dev \
python3-distutils rsync unzip zlib1g-dev file wget
2

拉取源码

克隆 chawrt 仓库到本地：

git clone https://github.com/liudf0716/chawrt.git
cd chawrt
3

更新 feeds

更新并安装软件包源：

./scripts/feeds update -a
./scripts/feeds install -a
4

配置编译选项

使用 menuconfig 配置目标设备和功能模块：

# 使用预设配置（可选）
cp configs/your-device.config .config

# 或手动配置
make menuconfig
配置说明：
  • Target System: 选择你的设备平台（如 MediaTek Ralink MIPS、Rockchip ARM 等）
  • Target Profile: 选择具体设备型号
  • LuCI → Applications: 选择需要的功能模块
5

开始编译

首次编译建议单线程以便查看错误信息：

# 下载所需软件包
make download V=s -j$(nproc)

# 开始编译（首次建议单线程）
make V=s

# 后续编译可使用多线程
make -j$(nproc)
注意：首次编译可能需要 1-3 小时，具体时间取决于网络速度和硬件性能。
6

获取固件

编译完成后，固件位于：

bin/targets/<platform>/<subtarget>/

固件文件通常包括：

  • *-squashfs-sysupgrade.bin - 用于升级已安装 OpenWrt 的设备
  • *-squashfs-factory.bin - 用于从官方固件刷入
  • *-initramfs-kernel.bin - 临时启动镜像（不会写入 flash）

常见编译问题

编译失败：下载软件包超时

解决方案：

  1. 使用国内镜像源加速下载
  2. 手动下载失败的包到 dl/ 目录
  3. 重新执行 make download V=s
软件包依赖冲突

解决方案：

  1. 检查 make menuconfig 中是否选择了冲突的包
  2. 清理编译缓存：make clean
  3. 重新配置并编译
内核模块编译错误

解决方案：

  1. 确认内核版本与模块兼容
  2. 检查是否安装了所有依赖包
  3. 查看详细错误信息：make V=s
磁盘空间不足

解决方案：

  1. 编译至少需要 20GB 可用空间
  2. 清理旧的编译文件：make clean
  3. 删除下载缓存：rm -rf dl/（谨慎操作）

清理命令

命令 说明
make clean 删除编译生成的文件，保留配置和下载的包
make dirclean 删除编译文件和交叉编译工具链
make distclean 完全清理，包括配置文件（不删除 dl/ 目录）

设备支持列表

以下是 chawrt 已支持的设备型号及刷机教程。更多设备支持持续更新中。

CMCC RAX3000M

MediaTek MT7981
▼

设备规格

  • CPU: MediaTek MT7981B (2×ARM Cortex-A53 @ 1.3GHz)
  • RAM: 256MB DDR3
  • Flash: 128MB SPI NAND
  • WiFi: MT7981 (2.4G) + MT7976 (5G) WiFi 6
  • 端口: 3×GbE LAN + 1×GbE WAN

刷机步骤

  1. 准备工作
    • 下载 chawrt 固件：cmcc-rax3000m-squashfs-factory.bin
    • 准备网线连接电脑和路由器 LAN 口
    • 备份原厂固件（可选）
  2. 进入 Breed/Uboot
    • 断电状态下按住 Reset 键
    • 上电 5-10 秒后松开 Reset
    • 电脑 IP 设为 192.168.1.2，访问 192.168.1.1
  3. 刷入固件
    • 在 Breed/Uboot 界面选择"固件更新"
    • 上传 factory.bin 文件
    • 等待刷写完成并重启
  4. 首次启动
    • 等待 2-3 分钟系统初始化
    • 访问 192.168.1.1 进入 LuCI 界面
    • 默认无密码，首次登录需设置

恢复原厂

如需恢复原厂固件，可在 Breed/Uboot 中刷入官方固件备份，或使用电信运营商提供的恢复工具。

常见问题

刷机后无法启动

检查是否使用了正确的固件型号，RAX3000M 需使用专用固件。如 Breed 仍可访问，重新刷入尝试。

WiFi 无法使用

首次启动后需在 LuCI 界面手动配置 WiFi SSID 和密码，然后启用无线。

FastRhino R66S

Rockchip RK3568
▼

设备规格

  • CPU: Rockchip RK3568 (4×ARM Cortex-A55 @ 2.0GHz)
  • RAM: 1GB/2GB/4GB DDR4
  • Flash: 8GB eMMC + TF 卡槽
  • 网络: 2×2.5GbE (RTL8125B)
  • 扩展: USB 3.0, HDMI

刷机步骤

  1. 准备工作
    • 下载 chawrt 固件：r66s-squashfs-sysupgrade.img.gz
    • 准备 TF 卡（建议 8GB 以上，Class 10）
    • 下载烧录工具：balenaEtcher 或 Rufus
  2. 制作启动卡
    • 解压 .img.gz 得到 .img 文件
    • 使用烧录工具将镜像写入 TF 卡
    • 等待写入完成并校验
  3. 启动系统
    • 插入 TF 卡到 R66S
    • 上电启动，系统将从 TF 卡引导
    • 等待 LED 指示灯稳定
  4. 写入 eMMC（可选）
    • SSH 登录：ssh root@192.168.1.1
    • 执行安装脚本：install-to-emmc.sh
    • 完成后移除 TF 卡重启

恢复原厂

使用 Rockchip 线刷工具和官方固件包恢复 eMMC。或直接使用官方固件 TF 卡启动。

常见问题

TF 卡无法启动

检查 TF 卡是否正确烧录，尝试重新烧录或更换 TF 卡。确认 R66S 支持 TF 卡启动（部分批次可能需要修改 bootloader）。

2.5G 网卡无法识别

确认内核已包含 RTL8125 驱动。可在 LuCI 的系统日志中查看网卡识别情况。

Newifi D2

MediaTek MT7621
▼

设备规格

  • CPU: MediaTek MT7621AT (2×MIPS 1004Kc @ 880MHz)
  • RAM: 512MB DDR3
  • Flash: 32MB SPI NOR (GD25Q256)
  • WiFi: MT7603 (2.4G) + MT7612 (5G)
  • 端口: 3×GbE LAN + 1×GbE WAN + USB 3.0

刷机步骤

  1. 准备工作
    • 下载 chawrt 固件：newifi-d2-squashfs-sysupgrade.bin
    • 确认已刷入 Breed 引导（强烈推荐）
    • 网线连接电脑和路由器
  2. 进入 Breed
    • 断电按住 Reset 键
    • 上电 5 秒后松开
    • 浏览器访问 192.168.1.1
  3. 刷入固件
    • 选择"固件更新"
    • 勾选"自动重启"
    • 上传固件并刷写
  4. 访问系统
    • 等待重启完成（约 2 分钟）
    • 访问 192.168.1.1
    • 初次登录设置密码

恢复原厂

如已刷入 Breed，可在 Breed 界面刷入原厂固件备份。未刷 Breed 的设备可使用官方救砖工具恢复。

常见问题

如何刷入 Breed

搜索"Newifi D2 Breed 刷入教程"，通常可通过官方固件漏洞或 TTL 串口刷入。Breed 可避免变砖风险。

USB 3.0 无法识别硬盘

检查是否安装了 USB 存储相关内核模块（kmod-usb-storage、kmod-fs-ext4 等）。部分固件默认未包含。
